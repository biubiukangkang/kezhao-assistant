## 2026-09-19 QMuse 平台迁移校验的两个拦截

**现象**：`qmuse import` 失败：
1. `Existing TanStack root layout contains unsupported providers or UI: @/components/ui/sonner:Toaster`——根布局（__root.tsx）不允许挂全局 provider/Toaster。
2. `Conflicting configuration paths: "/", "/"`——平台打包器把 `_app.tsx` + `_app/index.tsx` 结构解析出两个 "/" 路由（本地 tsr generate 无冲突，服务端必炸）。`--force` 也救不了。

**解法（已固化进代码结构）**：Toaster 下沉到 PageShell / camera / course-album 各页面；routes 目录完全平铺（不用 pathless layout 目录），Tab 页共用壳组件 page-shell.tsx。
**注意**：平台上的"发布"动作在 QMuse 网页端（CLI 只到导入生成版本+发布产物），需账号登录网页操作。

## 2026-09-19 Vite dev server 在 Windows 卡旧代码

**现象**：改完代码 `curl 模块 URL` 返回的仍是旧 transform 结果，日志无 HMR 记录；重启 `npm run dev` 报"Port 5173 is already in use"——TaskStop 只杀了 npm 外壳，node/vite 子进程（PID 在 `netstat -ano | grep :5173`）残留。已通过 vite.config.ts 开 `server.watch.usePolling` 根治大部分场景，但个别文件仍可能漏，重启是兜底。

**排查口诀**：先 `curl '模块URL?tsr-split=component'` 看是否新代码（主文件只有壳，grep 主文件会误判"没生效"）→ 旧则杀 PID 重启。
