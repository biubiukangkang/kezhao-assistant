## 2026-09-19 浏览器自动化测 UI 的坑

**现象**：IAB（in-app browser）冒烟测试时：
1. Playwright 高级 click 对存在且可见的按钮（elementFromPoint 确认无遮挡）仍 3000ms 超时；Radix Select 的 option 点击同样超时。
2. hash 路由 Link 点击后 500ms 内快照还是旧页面（渲染延迟）。

**绕过**（已验证稳定）：
- 页面跳转直接 `tab.goto("http://…/#/路径")`。
- 点击一律 `evaluate` 原生 `btn.click()`。
- React 受控 input 用原生 setter + `dispatchEvent(new Event('input', {bubbles:true}))` 填值。
- 文件上传测试（IAB 不支持 file chooser）：`evaluate` 里 canvas 画图 → `new File([blob], name, {lastModified})` → DataTransfer 赋给 `input[type=file]` → dispatch change，可端到端测导入链路。

## 2026-09-19 Vite dev server 在 Windows 卡旧代码

**现象**：改完代码 `curl 模块 URL` 返回的仍是旧 transform 结果，日志无 HMR 记录；重启 `npm run dev` 报"Port 5173 is already in use"——TaskStop 只杀了 npm 外壳，node/vite 子进程（PID 在 `netstat -ano | grep :5173`）残留。

**绕过**：`taskkill //F //PID <pid>` 杀干净再重启；改完代码后若页面行为不对，先 curl 模块 URL 确认 server 是否吐新代码（组件体在 `?tsr-split=component` 子模块里，主模块只有壳）。
