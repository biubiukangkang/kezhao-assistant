> 配套 PRD：[PRD.md](./PRD.md) · 版本 v1.0（2026-09-19）

## 1. 架构总览

```
React 19 + Vite + TanStack Router（文件式路由）+ Tailwind 4 + shadcn/ui（46 组件已就绪）

```

## 2. 数据模型（与 QMuse 云表同构，W3 切云时字段一一对应）

```ts
interface Course {
  id: string; name: string; color: string; teacher?: string; createdAt: number;
}

interface ScheduleSlot {
  id: string; courseId: string;
  weekday: number;          // 1=周一 … 7=周日
  startMin: number;         // 距当天 00:00 的分钟数（节次换算产物）
  endMin: number;
  weekStart: number;        // 学期周次，1 起
  weekEnd: number;
  oddEven: "all" | "odd" | "even";
}

interface Photo {
  id: string;
  courseId: string | null;  // null = 待分类
  capturedAt: number;       // 归档用的时间戳（ms）
  capturedSource: "exif" | "mtime" | "manual";
  storageKey: string;       // 本地 = blob 在 IndexedDB；云 = 文件 ID
  matchMethod: "auto" | "manual" | "ai" | "unmatched";
  batchId: string;
  starred: boolean;
  width?: number; height?: number;
  createdAt: number;
}

interface AppSettings {    // meta 表，单条 KV
  semesterStart: string;   // 学期第 1 周周一，ISO 日期 YYYY-MM-DD
  periods: { startMin: number; endMin: number }[];  // 节次时间表，UI 按节次选，存储按分钟
}
```

默认节次（大学生常见大节，可在设置改）：

| 节 | 时间 |
|---|---|
| 1-2 | 08:00-09:35 |
| 3-4 | 10:05-11:40 |
| 5-6 | 14:00-15:35 |
| 7-8 | 16:00-17:35 |
| 9-10 | 19:00-20:35 |

## 3. 匹配算法（第一性原理推导：本质是时间区间命中）

```ts
function matchPhoto(t: number, slots: ScheduleSlot[], s: AppSettings): ScheduleSlot | null {
  // 1. t → (weekday 1-7, minutes, semesterWeek)
  //    semesterWeek = floor((当天0点 - semesterStart) / 7天) + 1，<1 或 >30 视为学期外
  // 2. 严格命中：weekday 相等 && week 在 [weekStart, weekEnd] && oddEven 匹配
  //    && startMin <= minutes <= endMin
  // 3. 未中 → 放宽 ±15 分钟（提前到教室拍 / 下课铃响后拍），多命中取 startMin 距 minutes 最近
  // 4. 仍无 → null（待分类）
}
```

边界规则：
- 学期外（week 越界）不参与匹配 → 待分类
- 放宽窗口仅作用于时刻，不作用于星期/周次
- 同一课程多个 slot 各自独立命中，取最近开始

## 4. 存储设计

- **IndexedDB**（库名 `kezhaodb` v1）：`courses`（keyPath id）、`slots`（id + index courseId）、`photos`（id + index courseId/batchId）、`meta`（KV）
- 照片 Blob 直接存 `photos` 记录 `blob` 字段（IndexedDB 原生支持 Blob）；展示用 `URL.createObjectURL`
- 全部经 `src/lib/db.ts` 暴露的 CRUD 访问，页面不直接碰 IndexedDB；W3 切云时替换 `db.ts` 实现为 QMuse 云 SDK 调用，页面不动

## 6. UI 实现要点

- 周视图：CSS Grid，7 列横向可滚（手机挤是常态，超级课程表同款处理）；节次行高固定；课程块用课程色 12% 底 + 左侧 3px 色条
- 添加课程：shadcn Dialog；颜色 8 色预设；节次用 Select（1-2/3-4/…可多选连续）；周次用双 Slider 或两个 Input
- 空态：课程库/首页照片区均带引导按钮（负面清单第 5 条）
- Toast 用 sonner（已装）；删除确认用 AlertDialog（轻确认一次）

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| iOS HEIC exifr 支持有限 | 兜底 file.lastModified；产品文案不承诺 100% |
| 微信/QQ 保存图无 EXIF | 修改时间兜底 → 待分类显式入口 + 手动改派 |
| 50+ 张批量解析卡顿 | 分批（每批 5 张）解析 + Progress 进度条 |
| 压缩图丢 EXIF | 选图不压缩（File API 直读原文件），无此问题；提示用户选原图 |
| 学期锚点填错全盘错 | 设置页实时预览"当前是第 N 周"反馈 |
