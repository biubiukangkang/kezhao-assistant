## 1. 架构总览

```
React 19 + Vite 7 + TanStack Router（文件式路由 + hash history）+ Tailwind 4 + shadcn/ui
数据层：IndexedDB（idb 封装），本地优先；照片入库前压缩到长边 2048
EXIF：exifr（拍摄时间优先，mtime 兜底）
课表导入：SheetJS（教务 .xls/.xlsx）+ 行式文本粘贴解析
云服务：QMuse 云服务已接入（appwrite.ts 基础设施 + school_portal 表预留），当前无业务消费方，APP 线为死代码不初始化（参赛网页版封存）
部署：qmuse import .（平台自动构建生成版本，发布动作在 QMuse 网页端）
安卓 APP：Capacitor 8 壳（android/ 工程，cn.kezhao.assistant，竖屏锁定），同一份 web 构建产物双目标输出
```

## 1b. 安卓 APP 架构（2026-09-21 v1.1 更新）

- **壳**：`npm run app:*` 三脚本（sync/debug/release）；webDir=dist；竖屏锁定；JDK 21 构建；versionCode 递增覆盖升级。
- **相机（v1.1，v1.3 重构）**：原生端 `@capacitor/camera` 调系统相机 App（`takePhotoWithSystemCamera`：quality 100 不重采样、EXIF 拍摄时间保留——插件重写文件后 copyExif 写回 DateTimeOriginal；**saveToGallery 必须为 false**：开 true 时 DCIM 原图 + Pictures 压缩镜像在相册时间线出现两张同图，实测不可接受）。v1.3 拍照归档改为两段式：`suggestShot(t)` 预检（匹配纯函数 + 缺配置时返回人话原因：未设学期锚点/课表空/时间不在学期/没课）→ 拍后确认卡（自动识别《XX》+ 节次 → 就归这门 / 换一门 / 先待分类）→ `archiveShot(blob, t, source, {courseId})` 入库（用户确认过 = manual）；确认后本批连拍沿用该课程不再弹卡，批次条可随时换。webview getUserMedia 取景仅存于 web 分支。
- **本地插件 `GalleryStorePlugin.java`**（app 模块内，MainActivity 注册；**保持 ASCII-only**，见踩坑日志 javac GBK 坑）：
  - `savePhoto`：MediaStore 写 `Pictures/课照助手/<课程名>/`（v1.1 起按科目子文件夹，无课程归「待分类」）；写入前先删同目录同名旧记录（MediaStore insert 同名会自动改 "(1)"，必须手动删旧保幂等）。
  - `deleteAlbumFiles`：清相册顶层旧布局文件（迁移用；owner 过滤，尾斜杠匹配）。
  - `openFolder`：优先 DocumentsContract 直达 `Pictures/课照助手`（部分国产 ROM 无响应），失败自动回退打开系统相册，resolve 返回 `{via: "files"|"gallery"}` 供 JS 端文案区分。
- **适配层 `src/lib/native.ts`**：`isNativeApp()` + 相册写入（subjectFolder 课程名清洗）+ 系统相机 + 备份分享 + `galleryAutoSave` 开关 + `migrateAlbumStructure`（升级首次进设置页自动把平铺镜像重排为科目子文件夹：删顶层旧镜像 → 主库全量重写，meta KV `albumStructure=2` 标记，幂等可重试）。
- **已知边界**：卸载重装会使 MediaStore 旧镜像 owner 变 NULL（孤儿），应用无权静默删除——旧文件留在相册但新照片不受影响，需用户手动清理；正常覆盖升级无此问题。
- **签名**：自签 keystore（android/keystore.properties，gitignore）；丢失无法覆盖升级。



## 2. 数据模型（IndexedDB：kezhaodb v2）

```ts
Course  { id, name, color, teacher?, createdAt }
ScheduleSlot {
  id, courseId, weekday(1-7), startMin, endMin,
  weeks?: number[],        // 任意周次组合（新数据，优先使用）
  weekStart, weekEnd,      // 旧字段，新数据保存时双写 min/max
  oddEven: "all"|"odd"|"even"  // 旧字段，按 weeks 推导
}
Photo {
  id, courseId|null(待分类), capturedAt, capturedSource("camera"|"exif"|"mtime"|"manual"),
  storageKey, matchMethod("auto"|"manual"|"ai"|"unmatched"), batchId, starred,
  note?,                   // 用户备注（QQ 空间式显示在照片上方）
  sourceKey?,              // 去重键 `${size}-${解析后时间}`（v2 起有 by-source 索引，查重 O(log n)）
  thumb?,                  // 列表缩略图（长边 480 JPEG 0.75，入库时生成；旧数据相册页分批回填）
  deletedAt?,              // 删除时间；存在 = 回收站中，30 天后惰性清理
  blob, createdAt
}
photos 索引：by-course / by-batch / by-source(v2)
AppSettings { semesterStart("YYYY-MM-DD"周一，设置页自动对齐周一), periods: Period[](节次可增删) }
meta 表：settings KV + photoFolder(同步文件夹句柄) + backupReminder(备份提醒基线)
```

规则：读周次一律走 `weeksOf(slot)`（weeks 优先、旧字段回退），展示走 `slotWeekLabel(slot)`（"1-16周"/"单周"/"1-3,5-7周"）。删除课程时照片回待分类（courseId=null、matchMethod=unmatched），不丢照片。

## 3. 归档匹配算法（lib/match.ts，纯函数）

照片时间 → (星期, 当天分钟, 学期周次)，学期周次由 `semesterStart` 锚点算出（1-30 周外不匹配）。
先严格匹配（时段内），未中放宽 ±15 分钟（刚上课/刚下课）；**放宽窗口同时命中前后两节课时（课间拍摄），优先归刚下课那节（endMin 最近）——下课铃后抢拍板书是最高频场景；只命中将上课的课时才归它**。时间来源：camera=拍摄时刻；导入=EXIF DateTimeOriginal/CreateDate 优先、mtime 兜底；用户可在查看器手动修正（source 变 manual，v1.2 起改时间会**真正按新时间重新匹配课表**）。
课表是入库时点的一次性判定（事实化归档），课表/锚点变更后用 `rematchPhotos()`（待分类页「重新匹配」入口）对全库 manual 之外的 photos 重算。

## 4. 存储、压缩与备份

- **压缩入库**（lib/archive.ts `compressWithThumb`）：所有照片入库前一次解码复用 bitmap——长边压到 2048、JPEG 0.9，顺带生成 480 长边缩略图（`photo.thumb`）供列表渲染；解码失败（如 HEIC）原样保存、无缩略图。旧数据无 thumb 时列表回退全图，相册页进入后分批后台回填（每批 4 张）。
- **去重**：sourceKey = `${file.size}-${解析后拍摄时间}`，v2 起走 photos 的 by-source 索引查重（O(log n)，不再全表扫描），重复导入跳过。
- **回收站**：删除为软删除（Photo.deletedAt 标记），设置页回收站可恢复/彻底删除/清空，30 天超期由首页加载时惰性清理（purgeExpiredPhotos，单事务）。listPhotos 默认排除已删，备份（listAllPhotos）含回收站。
- **照片出口**（lib/photo-export.ts）：查看器单张「保存或分享」、相册页批量导出——Web Share API 可用（手机）调起系统分享面板（10 张一批），桌面逐张 a[download] 兜底。
- **备份提醒**：新增照片满 30 张且距上次提醒超 24h，首页 toast 提醒导出；导出成功后重置基线（meta.backupReminder）。
- **恢复预览**：选择备份文件先 inspectBackup 解析展示（导出时间/课程/照片/星标/体积 + 当前库对比 + 覆盖警告），确认后才 importBackup 覆盖。
- **照片文件夹镜像**（lib/photo-folder.ts，File System Access API）：用户在设置里选一次文件夹，新照片自动写入真实 .jpg（文件名含日期/时间/课程名）；支持重新授权/全量同步/停止。仅 Chromium 系支持，不支持时 UI 降级说明。IndexedDB 始终是主存储，文件夹是单向镜像。
- **备份**（lib/backup.ts，v1.2 重构）：`backupChunks()` 流式产出 JSON 文本块（头部一块 + 每张照片一块），网页端收集进 Blob 下载；原生端逐块 appendFile 写缓存文件再调系统分享（内存占用恒定，几百张照片不 OOM）。thumb 不进备份，恢复后由相册页回填。**恢复原子化**：先在写库前把全部记录（含 blob）解析构造完，最后经 `replaceAllData` 单事务清写 courses/slots/photos+settings——任何失败都发生在清库之前；meta 其余键（文件夹句柄/相册开关等本机配置）跨恢复保留。

## 5. 课表导入（三条路）

0. **AI 识别导入（v1.4，APP 专用，推荐入口）**（lib/timetable-ai.ts）：教务课表**截图（可多张）/ 粘贴文字** → 内置 OpenAI 兼容 API（CapacitorHttp 原生请求免 CORS；`AI_BASE_URL/AI_API_KEY/AI_MODEL` 常量内置于代码，内测私有仓库）→ 结构化 prompt（含用户 periods 换算大小节）→ 严格校验产出 ParsedRow[] → 复用预览/导入链路。截图压长边 1280 再传；识别不出抛人话错误。Key 未配置时入口提示联系开发者。
1. **文件导入**（lib/timetable-xls.ts）：教务 .xls/.xlsx 矩阵课表（列=星期、行=第X大节、格子=名称/教师/断续周次/教室，一格多课自动切分），SheetJS 解析。
2. **文本粘贴**（lib/timetable-parse.ts）：每行一节课的文本（"高等数学 周一 1-2节 1-16周"），token 剥离法解析，失败行标红可剔除。
两条路都产出 ParsedRow → 预览（components/timetable-preview.tsx 共用）→ 确认后 `applyTimetable` 替换现有课表（同名课程照片归属保留，消失课程照片回待分类）。节次换算：小节号"3-4节"= 大节索引 1（每大节 2 小节）。**v1.2 起节次时间以用户设置的 periods 为准（解析与换算都传参），不再用内置默认作息表**。

> **决策记录（2026-09-20）**：教务系统在线抓取方向已彻底移除（入口、portal 服务、fetch-timetable 云函数、自动登记）。第一性分析结论：各校教务系统异构长尾（六大家 × 登录/验证码/可达性各不相同）、可达性持续收紧（统一认证 + 校园网锁）、对抗性运维成本高、验证必须有真实账号，投入产出结构性不划算。正方系适配器代码曾验证到"登录表单被真实服务器接受"的程度后按决策删除。后续课表导入增强方向：课表截图 AI 结构化提取（无需账号、一次开发全量用户可用，PRD Roadmap 原有方向）。schema 中 school_portal 表因平台 append-only 演进规则不可移除声明，业务代码已无引用（云面板可手动清理）。

## 7. 平台约束（QMuse，违反会被迁移校验拦截）

- **根布局（__root.tsx）禁止挂全局 provider/Toaster 等组件**——Toaster 已下沉到 PageShell / camera / course-album。
- **routes 目录必须平铺，不要用 `_app.tsx` + `_app/` 目录结构**——平台打包器会解析出重复的 "/" 路由导致导入失败。
- 部署 = `npm run build` → `qmuse import .`；应用绑定在 `.qmuse/project.json`（勿动、勿复制）。
- **平台上的"发布"动作在 QMuse 网页端**（CLI 只到生成版本+发布产物），需账号在网页操作。

## 8. 开发环境注意事项

- vite.config.ts 已开 `server.watch.usePolling`（Windows 默认监听会丢事件吐旧代码）；改完代码若页面行为不对，先 curl 模块 URL 确认 server 是否吐新代码——**组件体在 `?tsr-split=component` 子模块**，路由主文件只有壳。
- 端口 5173 残留进程：`netstat -ano | grep :5173` 找 PID 后 `taskkill //F //PID`。
- npm 源直连常超时：装依赖加 `--registry=https://registry.npmmirror.com`。
