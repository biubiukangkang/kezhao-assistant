# 课照助手 PRD

> 支付宝「智能体涌现大赛」参赛作品 · 产品需求文档
> 版本：v1.0（2026-09-19）· 代号「课照助手」，正式名待定（候选：课片 / 板书管家 / 随堂归档）

## 1. 一句话定位

大学生拍完板书/PPT 不用管，打开即已按课程、按日期归档好，复习时一搜一个准。

**产品叙事（比赛用）**：时间引擎 + AI 视觉引擎双驱动的课堂照片智能体——不是手动整理工具，是自动归档助手。

## 2. 用户与痛点

**目标用户**：经常在课堂拍板书/PPT 的大学生。

**痛点链**：
1. 课后照片堆积——一学期几百张混在相册里
2. 手动按课程整理麻烦——建相簿、逐张挑，没人坚持得下来
3. 复习时找不到——考前想翻某节课的板书，只能刷相册凭记忆找

**为什么现在做**：照片自带拍摄时间（EXIF），课表是结构化时间表，两者天然可对齐——"按时间自动归类"是零成本的正确答案，只是没人把它做成产品。

## 3. 设计规范（硬性约束，验收逐条对照）

### 3.1 范式对标：不发明新交互

| 模块 | 对标 | 借用范式 |
|---|---|---|
| 照片流/相册 | 系统相册（iOS/华为/小米） | 日期分组 header、网格缩略图、点开全屏左右翻 |
| 课表录入 | 超级课程表 | 周视图网格、点空格加课、节次/周次/单双周 |
| 导航/批量操作 | 微信 | 底部 3 Tab；选完顶部计数、底部确认按钮 |
| 首页 | 支付宝首页 | 服务卡片 + 大按钮，轻工具感 |

### 3.2 「不反人性」负面清单

1. 不强制登录即可用核心功能
2. 无开屏广告、评分弹窗、引导浮层轰炸、推送索要
3. 导入即所见：不静默改图、不偷传云端（本地优先）
4. 自动归类永远可一键改派；「待分类」是显式待办入口，不是死角
5. 空状态必带引导动作（"还没有课表，30 秒录入第一节课"），不放空白页
6. 批量导入 50+ 张必须有进度条与分批结果，不白屏转圈
7. 删除轻确认、无连环弹窗；文案说人话（"没认出这是哪节课，点一下选课程"）
8. 主导航与确认按钮在下半屏拇指热区，可点区域 ≥ 44px

## 4. 信息架构

底部 Tab（微信范式）：

- **首页**：今日课程卡 + 「导入照片」大按钮 + 最近归档动态
- **课程库**：相簿式课程列表 → 课程相册（日期分组网格 → 全屏翻页）
- **设置**：学期锚点（第一周周一）、节次时间表、数据管理

全屏页（无底部导航）：导入流程、归档确认、照片查看器、课表编辑。

## 5. 功能范围

### P0（W1-W2，缺一不可演示）

| # | 功能 | 要点 |
|---|---|---|
| 1 | 课表管理 | 周视图网格；点空格添加（课程名+颜色+星期+节次范围+周次范围+单双周）；点课程块编辑/删除 |
| 2 | 批量导入 | 多选照片 → 前端解析 EXIF 拍摄时间 → 匹配当日课表自动归课程；无 EXIF 用文件修改时间兜底；不中进「待分类」 |
| 3 | 归档确认 | 按课程分组预览本次结果；逐张/批量改派；确认入库 |
| 4 | 课程相册 | 课程 → 日期分组网格 → 全屏翻页复习 |

### P1（W3 打磨）

5. 待分类清理流（一键批量指定课程）
6. 照片删除、星标（重点板书）、导出
7. 移动端适配打磨（真机顺滑为验收标准）

### P2（W3 视工期二选一，比赛亮点）

8. **AI 视觉辅助归档**：时间匹配失败时，多模态识别照片内容建议课程（支撑"智能体"叙事）
9. **板书 OCR 搜索**：搜"泰勒公式"直达那张板书

### 非目标（明确不做）

- 不做相机/拍摄功能（用户用系统相机，尊重既有习惯）
- 不做社交、分享、社区
- 不做跨端同步承诺（W3 再评估云同步）
- 不接支付宝课表导入（比赛版明确砍掉，列为 Roadmap）

## 6. 核心流程：批量导入

```
选/拖照片（N 张）→ 逐张解析时间（EXIF→修改时间兜底）→ 课表匹配
  ├─ 命中唯一课程 → 自动归档（绿色标记"自动"）
  ├─ 命中多个 → 取开始时间最近者（可改）
  └─ 未命中 → 待分类（黄色标记，显式入口）
→ 确认页：按课程分组预览 + 改派 → 入库 → 课程相册可查
```

**匹配规则**：照片时间 → 解出（星期几，当天第几分钟，学期第几周）→ 命中条件 = 星期一致、周次在范围内（含单双周）、时间落在节次时段内（先严格匹配，未中再放宽 ±15 分钟，放宽时取开始时间最近者）。

## 7. 比赛叙事对齐（评选标准）

- **有用**：高频真实痛点，演示"30 张照片一键归 5 门课"冲击力强
- **有趣**：时间引擎的"魔法感"——照片放进去自己排队进相簿
- **热度**：大学生人人拍板书，答辩现场可现场演示手机操作
- **可持续**：Roadmap 有 OCR 搜索/AI 归档/多校课表导入
- **可经营**：本地优先零成本起步；云同步/会员增值可后置
